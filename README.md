# Claude Whitteron (1891–1918)

A memorial page for Second Lieutenant Claude Whitteron, 1st/6th Battalion, West Yorkshire Regiment (Prince of Wales's Own), who died on 25 April 1918 aged 27 and is commemorated on the Tyne Cot Memorial.

## Files

- `index.html` — summary page: the facts of Claude's life, his probable journey through the war, and maps
- `book.html` — the full text of the family book
- `images/` — photographs and document scans used by the page

## Publishing on GitHub Pages

1. Create a new public repository on GitHub (e.g. `claude-whitteron`).
2. Upload `index.html`, `README.md`, `claude-whitteron-book.md` and the `images` folder (drag and drop on the repository page, then **Commit changes**).
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute the page will be live at `https://<your-username>.github.io/claude-whitteron/`.
